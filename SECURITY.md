# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of Anti-Gravity Piano seriously.

If you believe you have discovered a security vulnerability or sensitive data leakage in this repository:
1. **Do not disclose the issue publicly** on GitHub issues or community discussions.
2. Email a detailed disclosure report to the repository maintainers via security contact placeholder: `security-team@anti-gravity-piano.local`.
3. Include clear steps to reproduce, affected files, and potential impact.

We will acknowledge receipt within 48 hours and work with you on a patch before public disclosure.

## Security Practices
- **No Secrets**: Never commit API keys, signing certificates, keystore files, or sensitive environment tokens.
- **Local Storage**: All gameplay stats and settings are persisted locally on-device without third-party cloud transmissions.
