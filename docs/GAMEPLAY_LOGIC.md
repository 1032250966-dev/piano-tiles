# Gameplay Logic & Mathematical Specifications

## 1. Tile Generation Algorithm
Tiles are procedurally generated by `TileManager.js` across 4 columns [0, 1, 2, 3]:
- **Lane Selection**: A pseudo-random integer in range `[0..3]`.
- **Anti-Repetition Rule**: If the generated column matches `lastSpawnColumn`, a re-roll occurs with 65% probability to prevent unplayable single-lane stacking.
- **Initial Coordinates**:
  - `x = columnIndex * (screenWidth / 4)`
  - `y = -tileHeight` (spawns just offscreen above the viewport)

## 2. Tile Movement & Velocity Curve
Tiles advance downward each frame using delta-time physics:
```
y(t + dt) = y(t) + v * dt
```
Where:
- `dt` = Elapsed time between animation frames in seconds.
- `v` = Current falling velocity in pixels per second.

### Velocity Formula
$$v(\text{hits}) = \min(v_{\max}, v_{\text{base}} + (\text{hits} \times \Delta v))$$
- $v_{\text{base}} = 320\text{ px/s}$
- $\Delta v = 9.0\text{ px/s}$
- $v_{\max} = 950\text{ px/s}$

### Spawn Interval Formula
$$t_{\text{spawn}}(\text{hits}) = \max\left(t_{\min}, \frac{t_{\text{base}}}{1 + (0.018 \times \text{hits})}\right)$$
- $t_{\text{base}} = 750\text{ ms}$
- $t_{\min} = 240\text{ ms}$

## 3. Hit Detection & Precision Window
When a touch event occurs at coordinate $(x_{\text{tap}}, y_{\text{tap}})$:
1. Compute targeted column:
   ```
   col = floor(x_tap / (screenWidth / 4))
   ```
2. Query active untapped tiles in that column.
3. Compute distance between tile center and target strike line $Y_{\text{target}}$:
   ```
   distance = |y_tile + (tileHeight / 2) - Y_target|
   ```
4. Evaluate precision thresholds:
   - **PERFECT**: $\text{distance} \le 45\text{px}$
   - **GREAT**: $\text{distance} \le 90\text{px}$
   - **GOOD**: $\text{distance} \le 140\text{px}$
   - **MISS**: $\text{distance} > 140\text{px}$

## 4. Miss Detection Logic
During the tick loop, each tile's top position is tested against the miss threshold:
```
missLineY = targetHitLineY + tileHeight + 25px
```
If $y_{\text{tile}} > \text{missLineY}$, the tile is flagged as missed and removed from play. In Classic mode, this triggers an immediate `GAME_OVER`.

## 5. Scoring & Multiplier Formula
Points awarded per hit:
$$\text{Points} = \text{round}(\text{BaseScore} \times \text{Multiplier})$$
- Perfect: 100 pts
- Great: 75 pts
- Good: 50 pts

Multiplier tiers based on consecutive combo streak:
- $\text{streak} < 5$: 1.0x
- $5 \le \text{streak} < 15$: 1.2x
- $15 \le \text{streak} < 30$: 1.5x
- $30 \le \text{streak} < 50$: 2.0x
- $\text{streak} \ge 50$: 3.0x

Any miss resets the combo to 0 and multiplier to 1.0x.
