# Privacy Policy for Anti-Gravity Piano

**Effective Date**: September 8, 2026

## 1. Overview
Anti-Gravity Piano is an open-source mobile rhythm game designed with a strict **privacy-first** architecture. We believe games should be fun without compromising user privacy.

## 2. Data Collection
- **Zero Personal Information**: Anti-Gravity Piano does not collect, harvest, store, or transmit any personally identifiable information (PII), such as names, email addresses, phone numbers, or physical locations.
- **No User Accounts**: The application operates entirely without accounts, sign-ins, or cloud user profiles.
- **No Telemetry or Tracking**: The application does not include third-party advertising SDKs, analytics trackers, or telemetry beacons.

## 3. Local On-Device Storage
The game utilizes local storage on your device (such as `localStorage` or native device key-value storage) exclusively for:
- Saving personal high scores and combo records.
- Saving user preferences (audio volumes, mute states, and haptic feedback toggles).

This data never leaves your device and can be erased at any time via the in-game Settings menu ("RESET HIGH SCORES") or by clearing your application cache.
