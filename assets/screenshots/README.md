# Anti-Gravity Piano Screenshots

This directory houses interface screenshots and visual previews for the application.

## Screen Layouts Available
1. **Home Screen** (`home-preview.svg`): Title logo, high scores card, and play buttons.
2. **Gameplay Screen** (`gameplay-preview.svg`): 4-column lane system, floating neon tiles, target strike line, particle bursts, and score HUD.
3. **Game Over Screen** (`gameover-preview.svg`): Score summary, max combo, new record badge, and replay action.
4. **Settings Screen** (`settings-preview.svg`): Volume sliders, haptics toggle, and effect settings.
